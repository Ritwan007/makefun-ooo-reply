Entry for the [Funniest One-Line Out-of-Office Reply](https://make.fun/competitions/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) competition on make.fun.

`main.py` writes one line to `/output/entry.txt` — the winner of a local 38-candidate
round-robin gauntlet judged against the competition's published judge brief:

> Away until Monday. If the building is on fire, email Facilities. If it's my inbox, let it burn.

95 characters. A real away message with a return date and a redirect for urgent matters,
whose punchline lands on the first read.
